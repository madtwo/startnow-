# 研究资料：独立智能体与自然对话

来源：用户提供的 `一个压缩包.zip`（2026-11-16），原目录为 `StartNow_独立智能体与自然对话_开发交付包`。

这不是前端运行时依赖，也不是对线上模型的验收结论。它是设计参考、行为规范、回归场景和一份标准库隔离演示。

## 已经接进当前原型的内容

- `src/lib/dialogue.ts`
  - 判断一句公开评论是寒暄、语气词、玩笑、挑衅、求助、提问还是正常聊天。
  - 陌生人关系标签。
  - 演示模式下，对「小美女，你好呀」「额」「？」「哈哈」等短句给出短回应，而不是直接进入辅导或下一步。
- `src/lib/prompts.ts`
  - `PUBLIC_RULES`：论坛默认线上、双方不同处一地、评论不等于求助、短评可以短回、不虚构线下。
  - `commentPrompt` 加入当前回复对象、关系、原话和 `physical_copresence=false`。
  - 评论长度从固定的 40–100 字改为 4–100 字，允许短回。
- `src/lib/cards.ts`
  - mock 回复先走社交意图；只有最新发言来自玩家时才判断寒暄/语气词。
  - 删除了会邀请陌生人一起下楼的 mock 台词。

## 尚未接进当前原型的内容

- 真正的服务端鉴权、数据库行级权限、私聊可见性、曝光日志、删除链路。
- 独立 belief/observation 存储与置信度。
- 真实模型下的多次采样盲评。
- `configs/model_eval_cases.jsonl` 的自动回归。

这些属于生产级论坛要做的工程。当前原型仍然是单浏览器 localStorage，不能假装已经满足服务端隔离。

## 目录

- `README_从这里开始.md`：原包总览。
- `docs/`：需求、架构、自然回复协议、验收矩阵、上线门槛。
- `prompts/`：公共规则、单人上下文、单回合模板。
- `configs/`：角色配置、事件示例、记忆表结构、模型评估样例。
- `demo/` 与 `tests/`：Python 标准库隔离演示与测试，不参与前端运行。
- `reference/`：上一轮问题诊断、原始共创说明、旧角色卡；仅供核对。

## 运行原包测试

```bash
cd research/agent-dialogue-pack
python -m unittest discover -s tests -v
python demo/isolated_forum_demo.py
```

这些测试证明玩具后端的可见性/记忆隔离，不证明线上 LLM 的自然度或安全。
