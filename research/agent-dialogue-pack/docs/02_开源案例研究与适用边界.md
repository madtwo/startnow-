# 开源案例研究｜哪些能借鉴，哪些不能直接照抄

检索与核对日期：2026-11（公开项目说明及文档）。以下项目并未在 StartNow 中部署或实测；表中是从公开设计总结出的**可借鉴模式**。

## 1. AI Town（a16z-infra/ai-town）

- **公开资料**：https://github.com/a16z-infra/ai-town ；架构说明 https://github.com/a16z-infra/ai-town/blob/main/ARCHITECTURE.md
- **已公开的做法**：游戏世界有 Agent/Player/Conversation 等结构。角色谈话通过专门的对话层；每段谈话后提取摘要、生成向量，并在未来与对方交流时按关联检索；引擎有实际事件和行动。
- **StartNow 可借鉴**：**角色记忆绑定具体角色与发生过的对话**；人物互相影响，必须来自彼此确实参与/看到的交互，而不是给所有 agent 复用一段群体摘要。
- **不宜照搬**：AI Town 是带位置信息的虚拟小镇；StartNow 默认是**异地在线论坛**，不能继承「就在旁边」「一起走过去」的物理动作。

## 2. OASIS（camel-ai/oasis）——最贴近论坛

- **公开资料**：https://github.com/camel-ai/oasis ；https://github.com/camel-ai/oasis/blob/main/docs/key_modules/social_agent.mdx ；https://github.com/camel-ai/oasis/blob/main/docs/key_modules/platform.mdx
- **已公开的做法**：模拟 Twitter/Reddit 式的社交平台，支持发帖、互动、推荐与行为日志；`SocialAgent` 有唯一 `agent_id`、个人信息与记忆模块。项目明确以社交行为/传播为研究对象。
- **StartNow 可借鉴**：以 `agent_id + 事件（发帖/评论/转发/点赞）+ 可见范围 + 接触记录` 组织互动。决定是谁能看见一则评论，是产品/平台层职责，不是大模型猜测。
- **注意**：模拟社交平台也可能产生群体趋同或极化，用户要避免的是**没看见任何事件却同步变化**，不是阻止角色在看过相同公开证据之后产生类似想法。

## 3. Generative Agents（Park 等人，UIST 2023）

- **研究原文**：https://research.google/pubs/generative-agents-interactive-simulacra-of-human-behavior/ ；https://arxiv.org/abs/2304.03442
- **已公开的做法**：每个人物通过记忆流、观察、反思、计划形成行动，许多社会行为通过角色彼此交谈而逐步扩散。
- **StartNow 可借鉴**：个人长短期经历、可检索记忆与有来源的观察。每个角色不仅「知道什么」，还各自决定「这对我意味着什么」。
- **不宜照搬**：研究中角色有日程、场所与复杂模拟；StartNow 小论坛要保持低成本、短期轻量，不应强制角色每天运行、长期粘住用户。

## 4. LangGraph / LangMem（隔离命名空间）

- **公开文档**：https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/persistence.mdx ；https://github.com/langchain-ai/docs/blob/main/src/oss/langgraph/use-subgraphs.mdx ；https://langchain-ai.github.io/langmem/guides/dynamically_configure_namespaces/
- **已公开的做法**：短期会话用 thread checkpoint，长期存储用带 namespace 的 store。多子图需要稳定的独立 namespace，避免状态覆盖；LangMem 文档展示了动态用户/代理命名空间。
- **StartNow 可借鉴**：`thread_id` 要包含代理及回帖线程；长期记忆的命名空间带 `tenant_id`、`agent_id`。这里的 namespace 是重要的**数据组织手段**，还必须叠加服务端权限；否则有全库访问权的代码照样能读错区。

## 5. Letta（值得参考，也有反例）

- **公开文档**：https://docs.letta.com/v1-sdk/concepts/stateful-agents ；https://docs.letta.com/v1-sdk/memory/memory-blocks
- **已公开的做法**：有 agent 级持久状态/记忆；同时也支持多角色附着同一个 shared memory block，更新后他人也能看到。
- **StartNow 可借鉴**：每人一份持久 persona、情境与个人经历；「共享」仅用于只读规范、非私人的业务术语等。
- **特别避免**：绝不把一块可写的「大家对某用户的印象」「全员情绪」「群体价值判断」附着到四人身上，否则就是用户所担心的隐形共振来源。

## 6. Sotopia（不完全信息与社会互动评估）

- **公开资料**：https://github.com/sotopia-lab/sotopia ；https://sotopia.world/projects/sotopia ；https://docs.sotopia.world/concepts/agents
- **已公开的做法**：不同角色拥有自己的身份背景、隐含目标；以环境观察为输入，行动/说话为输出，研究社交协作、竞争与沟通。
- **StartNow 可借鉴**：每个人对同一事有**自己的信息和目标**，并非全知；测试中加入立场冲突、误解、修正，而不是只评价他们是否给了「正确建议」。

## 设计结论（并非某个项目原样提供的功能）

最佳组合：**OASIS 的论坛事件模型 + AI Town 的角色社交回忆 + LangGraph 的持久化隔离 + Sotopia 的不完全信息评估**。Letta 的共享块特性提醒我们：必须谨慎区分公用规则与可写私人记忆。

这些项目展示了可行设计方向，但没有任何一个能直接证明 StartNow 做到了安全隔离、人性化或互相独立。具体保证取决于 StartNow 实际实现与回归测试。
