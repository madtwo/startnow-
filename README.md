**你卡住时，四个 AI 同学先听你说，再陪你把第一步缩到小到不会失败；他们卡住时，你也去拉他们一把。**

## 评委先读

[STARTNOW_PRODUCT_MANUAL.md](STARTNOW_PRODUCT_MANUAL.md)

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173/`。默认演示模式，打开即用，不需要 API Key。

## 构建

```bash
npm run build
```

## 开发与交接
